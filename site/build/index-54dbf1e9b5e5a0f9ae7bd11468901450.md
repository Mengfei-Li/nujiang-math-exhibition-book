# 两道长期题，从看懂到讲透

## 写给怒江战队队员的数学学习书

两篇论文已经把研究结果压缩在有限的篇幅里。这本书做另一件事：把那些被压缩掉的思考过程重新展开。我们会从题目究竟在问什么讲起，慢慢走到模型、构造、证明和计算证书。这里的“证书”是能让别人独立复核结论的一组具体数据或界；沿途出现的其他新术语，也都会说明为什么非用不可。

读完以后，你不只要记得 285.492、445.858 或 57，更要能回答三件事：这个数在量什么，它在什么条件下成立，我们凭什么相信它。

</div>

## 两个故事从哪里开始？

第一题把一个圆形机器人放进三角形网格状的障碍阵列。机器人只能用转向、加速和减速三种卡片控制。障碍静止时，题目问的是：要穿出前 $n$ 层，最少要转多少次弯？障碍绕起点旋转时，题目换了目标：三类卡合计只能用 100 张，怎样让机器人安全到达尽可能远的地方？这两个小问共用同一片障碍阵列，却在优化不同的量。

第二题从九个标号点和六条固定线段开始。我们可以继续连线，目标是让图中出现至少 $k$ 个三角形，同时把总线段数压到最少。这里真正困难的不是数出某一个图里的三角形，而是证明：再少一条边，无论怎样连都不够。

一题要在连续运动中保证永不相撞，一题要在大量离散组合中证明已经最省。它们最终汇到同一条研究主线：

> 把现实问题变成清楚的数学模型，在有限规则中寻找构造，再用证明或可复核的计算说明它真的成立。

## 怎样开始读？

如果你第一次接触这两题，按左侧目录顺序读最省力。“先学会读研究”不会预讲完整答案，只会先交给你几件后面反复要用的工具：怎样分辨上界和下界，怎样看待计算结果，怎样把公式翻回普通语言。随后完整读完题一，再进入题二，最后用综合训练把两题串起来。

如果你正在准备答辩，可以先读每题的开场和总结，知道整幅地图，再回到中间章节补理由。带队教师则可以先看教师指南，按学生真正说不清的地方选择章节，不必追求整本书齐步走完。

| 阅读目的 | 建议走法 | 合适节奏 |
|---|---|---|
| 从头学懂 | 基础工具 → 题一 → 题二 → 综合训练 | 8—12 次，每次约 40 分钟 |
| 准备答辩 | 两题开场与总结 → 回查证明章节 → 模拟追问 | 4—6 次，每次约 45 分钟 |
| 组织训练 | 教师指南 → 结论边界 → 按薄弱点选章 | 6—8 个课时 |

## 四种说法，分量并不相同

研究中最容易出现的误会，不是小数记错，而是把一句话说得比证据更强。书中会反复遇到以下四种口径：

- <span class="claim-proved">已证明</span>：有完整、可以逐步检查的数学理由。
- <span class="claim-construct">已构造</span>：给出一个确实可行的方案。若研究量要尽量小（如卡片数、边数），构造给上界；若研究量要尽量大（如可达距离），构造给下界。
- <span class="claim-experiment">计算实验</span>：程序找到了现象或未找到反例；它的证明力取决于是否穷尽、是否有可核查证书。
- <span class="claim-conjecture">猜想</span>：证据支持，但目前仍缺严格证明。

这些标签不是装饰。把“猜想”说成“定理”，或者把“至少能到”说成“最远只能到”，都会把原来的结论换成另一个、更强却没有被证明的结论。

每章会尽量先说明眼前的困难，再引入解决它的图像、符号或程序。公式出现时，先问它在比较哪两个量；程序给出结果时，再问它检查的是若干例子还是全部可能。互动实验用来形成直觉、暴露误解，正式结论则仍要回到证明或证书。

<div class="checkpoint">

**出发前只记住一个习惯**

每看到一个结论，先补全一句话：“在什么条件下，我们用什么证据，证明了什么？”只要这句话能说完整，复杂的符号就有了落脚处。
