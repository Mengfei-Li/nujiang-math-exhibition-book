# 两道长期题，从看懂到讲透

## 怒江战队初中生版数学学习书

这不是把论文“翻译成简单句”，而是带你重新走一遍研究者走过的路：先看见问题，再提出模型；先做小例子，再写符号；先分清证据等级，再理解论文结论。

**读完的目标不是背出 285.492、445.858 或 57，而是知道这些数从哪里来、在什么条件下成立、哪些问题仍然没有解决。**

</div>

## 这本书讲哪两件事？

第一题像一场机器人闯关赛：许多圆形障碍物排成三角形网格。机器人有转向、加速、减速三类卡；每张转向卡可原地向左或向右转不超过 $5^\circ$，加速卡把速度乘以 $1.25$，减速卡把速度乘以 $0.8$。静态时我们研究穿出前 $n$ 层最少要几张转向卡；障碍物旋转时，则研究总共使用 100 张卡至少能走到离起点多远。

第二题像一场“用线段制造三角形”的搭建赛：九个或更多点中，有六条线段已经固定。我们继续加线，希望出现很多三角形，同时又想让总线段数尽量少。我们要研究：每个三角形目标至少需要多少条边？

表面上，一题讲运动，一题讲图形；深处却都在做同一件事：

> 把现实问题变成清楚的数学模型，在有限规则中寻找构造，再用证明或可复核的计算说明它真的成立。

## 三种推荐读法

| 你是谁 | 推荐路线 | 预计节奏 |
|---|---|---|
| 第一次接触论文的队员 | 按左侧目录顺序，从“先学会读研究”开始 | 8—12 次，每次 40 分钟 |
| 准备答辩的队员 | 每题先读“故事与模型”，再读“总结与答辩”，遇到不懂的概念向前回查 | 4—6 次，每次 45 分钟 |
| 带队教师 | 先读教师指南与结论边界，再按训练工作坊组织学生操作 | 6—8 个课时 |

## 本书的阅读符号

- <span class="claim-proved">已证明</span>：有完整、可以逐步检查的数学理由。
- <span class="claim-construct">已构造</span>：给出一个确实可行的方案。若研究量要尽量小（如卡片数、边数），构造给上界；若研究量要尽量大（如可达距离），构造给下界。
- <span class="claim-experiment">计算实验</span>：程序找到了现象或未找到反例；它的证明力取决于是否穷尽、是否有可核查证书。
- <span class="claim-conjecture">猜想</span>：证据支持，但目前仍缺严格证明。

这些标签不是装饰。答辩时把“猜想”说成“定理”，或者把“可达下界”说成“最大值”，会改变结论本身。

## 每章怎样学习

每个新概念都尽量走完六步：

1. 先从生活情境提出问题；
2. 用图像建立直觉；
3. 手算一个小例子；
4. 再写出符号和公式；
5. 回到论文看它解决了什么；
6. 用小测或实验确认自己真的会了。
