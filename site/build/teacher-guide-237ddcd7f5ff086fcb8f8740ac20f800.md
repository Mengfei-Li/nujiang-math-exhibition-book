# 教师指南：怎样带学生真正理解，而不是背答案

## 读者起点

本书假设学生会：

- 初中代数与勾股定理；
- 简单坐标和函数图像；
- 基本组合计数直觉；
- 阅读短段 Python 代码，但不要求独立编程。

反三角函数、图论、整数规划、Lipschitz界和区间算术都在使用前给直觉。学生不必先学完整高等课程。

## 每章统一六拍

1. **看**：先看无符号图，描述发生了什么；
2. **试**：操作滑块、纸模或小代码；
3. **译**：把观察翻成一句数学话；
4. **证**：再引入符号，说明理由与证据；
5. **辨**：修正一句典型过度表述；
6. **讲**：用30—90秒复述。

每次课最多完成两个循环。宁可少读一章，也不要让学生在“好像懂”时直接越过“辨”和“讲”。

## 建议八课时

| 课时 | 内容 | 当堂产出 |
|---|---|---|
| 1 | 结论阶梯、优化方向 | 每人给三条结论贴标签 |
| 2 | 禁圆、网格、第一层 | 手画膨胀图与30°垂距 |
| 3 | 第二层、9卡、线性阶 | 准确写出 $1\le C(2)\le9$ |
| 4 | 两个旋转模型、连续证书 | 两张条件分支卡 |
| 5 | 图论化、固定图、小 $k$ | 亲手搭出7、8、9、9 |
| 6 | 前沿、整数规划、计算证据 | 解释做到与不能更好两侧 |
| 7 | KK、$U_9$、57阈值 | 用12、29、30边做口算 |
| 8 | 最小度、附加限制、模拟答辩 | 两分钟完整讲解与同伴评分 |

## 分层安排

### 基础队员

必须掌握：

- 半径相加与相切条件；
- $C(1)$、$C(2)$ 的结论等级；
- 两个旋转模型不能混；
- 图、边、三角形与固定图；
- $E(n,1)$ 至 $E(n,4)$；
- 见证不等于最优。

### 主讲队员

在基础上增加：

- $4n+1$ 卡片账本与 $\Theta(n)$；
- 285方案的余量减位移；
- $T$ 与 $E$ 互逆；
- KK 的 $q,r$ 分解；
- $U_9$ 删点法与57阈值；
- 最小度三族。

### 证据队员

进一步负责：

- 连续区间证书的结构；
- 浮点方向与安全舍入；
- 三后端最优状态、零差距和见证重计数；
- 来源文件、冻结哈希与结论账本。

## 不建议的教学方式

- 一开始投整页论文，让学生逐行翻译；
- 要求背全部小数，却不问条件；
- 用动画替代安全证明；
- 把计算机辅助证明说成“AI算的”；
- 把尚未闭合区间补成猜想曲线；
- 只让最强的一名学生长期主讲。

## 提问顺序

当学生说错，不急着给答案，依次问：

1. 你研究的量是越大越好还是越小越好？
2. 这个例子证明“能做到”还是“不能更好”？
3. 你漏了哪个规则开关？
4. 若把你的句子理解得更强，能找反例吗？
5. 最保守、仍完全正确的说法是什么？

## 学习证据

每名队员至少保存：

- 一张自己画的模型图；
- 一次 Notebook 输出或互动实验记录；
- 一条被同伴纠正过的原回答；
- 一条修订后的标准回答；
- 一次90秒录音或现场计时讲解成绩。

这套记录比“读完了”更能说明训练进度，也便于比赛前快速定位薄弱点。
