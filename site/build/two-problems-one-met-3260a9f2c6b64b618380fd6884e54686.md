# 两道题，其实在练同一种研究能力

题一结束时，我们学会给连续运动的每一刻提供安全保证；题二结束时，我们学会在大量离散连接中证明边数已经最少。一题有圆、路线和时间，另一题有点、边和三角形，表面上相距很远。回头看研究过程，却会发现它们走过同一条主线：先删去无关细节，再找可行方案，最后补上“为什么不能更好”的证据。

## 把两段旅程并排来看

| 研究环节 | 长期题一 | 长期题二 |
|---|---|---|
| 现实对象 | 圆形机器人、圆障碍、动作卡 | 九个点、固定线段、继续加线 |
| 第一次抽象 | 机器人缩成点，障碍膨胀为半径9禁圆 | 忘掉位置，只保留顶点与边 |
| 离散语言 | 三角网格地址、层、卡片序列 | 边开关、三角形开关、固定图 $H$ |
| 构造 | 9卡路线、周期通道、两套100卡计划 | 小 $k$ 边集、colex、匹配构造 |
| 一侧的界 | 构造给 $C$ 上界、给 $D$ 下界 | 构造给 $E$ 上界，KK与删点给下界 |
| 精确性来源 | 小规模上下界相遇；其余保留区间或阶 | 手证、三后端精确前沿、解析上下界相遇 |
| 连续/离散风险 | 帧间碰撞、浮点误差、无限点阵 | 组合爆炸、模型编码、见证不等于最优 |
| 证书 | 卡片、转点、距离区间、位移上界 | 边集、三角形重计数、最优界、零差距 |

## 研究进行到任何一步，都可以问三个问题

### 我们究竟在优化什么？

$C$ 与 $E$ 要尽量小，$D$ 要尽量大。同一个构造在不同优化方向下给出不同方向的界。

### 一套方案证明了哪一半？

方案永远先证明“做得到”。要声称最优，还要证明“更好做不到”。题一的 $C(2)$ 仍缺这一半；题二的有限前沿由求解器最优界补齐这一半。

### 计算怎样变得可审计？

保存结果不够，还要保存输入范围、算法状态、见证、独立复核与数值误差处理。题一重视连续区间，题二重视离散最优界。

## 两次关键转弯都来自“反过来想”

题一把移动圆反过来变成“点避开膨胀圆”；题二把目标问题反过来变成“先给边预算求最大三角形”。好的建模往往不是正面硬算，而是换一种更容易核验的问法。

## 把方法交给同伴检验

一人任取一条结论，例如 $C(n)\le4n+1$ 或 $E(n,k)=\mu(k)$。另一人只允许问五个问题：

1. 研究量是什么？
2. 越大还是越小？
3. 适用条件是什么？
4. 哪个证据承担“做到”，哪个承担“做不到更好”？
5. 最容易说过头的版本是什么？

这五问没有要求背完整证明，却会暴露结论是否真的落了地。能让同伴追问而不丢条件，才算真正拥有这条结论。下一页把最常见的过度表述集中起来，看同一句话怎样从“差不多”修到准确。
