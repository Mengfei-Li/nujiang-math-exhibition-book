# 学习路线：先搭脚手架，再爬高楼

两篇正式论文写给评审，必须在很少的页数里装下许多信息。初学者若直接从第一页读到最后一页，常常会遇到三种困难：符号一下子太多、结论之间的关系不清、程序算出的数不知道该信到什么程度。

本书因此把“论文顺序”改成“学习顺序”。

## 第一阶段：先会判断一句结论有多强

先完成以下四页：

1. **结论阶梯**：分清例子、构造、下界、上界、精确值和猜想；
2. **数学工具箱**：补齐距离、坐标、函数、组合数和图的语言；
3. **计算证据**：知道搜索、穷举、优化器和证书分别在做什么；
4. 回到本页，用自己的话解释“为什么算到一个很好的方案不等于证明它最好”。

## 第二阶段：学习长期题一

推荐把一枚硬币当“机器人”，把杯垫当“障碍物”，在桌上同步操作。

- 第 1—3 章建立模型：机器人为何能缩成一个点？三角网格怎样编号？
- 第 4—5 章研究静止障碍物：从小规模到线性构造。
- 第 6—9 章研究旋转障碍物：先分信息模型，再看两套严格可行策略和连续时间证书。
- Notebook 实验负责“亲手改参数”；总结章负责“用两分钟讲清楚”。

完成标志：你能准确说出 $1\le C(2)\le 9$，并解释为什么 $C(2)=9$ 仍然只是猜想。

## 第三阶段：学习长期题二

推荐准备 9 个带编号的磁贴和一把直尺，用线绳代表边。

- 第 1—2 章把几何图形变成图，并读懂六条固定边；
- 第 3 章只用手算解决最小几个目标；
- 第 4—6 章理解精确前沿、整数规划、Kruskal–Katona 上限和九点固定结构的修正；
- 第 7—8 章处理最小度数与两种附加限制；
- Notebook 实验让你自己切换边，实时数三角形。

完成标志：你能解释为什么“有 $m$ 条边最多能有多少三角形”与“要 $k$ 个三角形至少要多少边”是同一个问题的正反两面。

## 第四阶段：变成队伍共同语言

最后完成综合部分：

- 用同一张表比较两题的“模型—构造—上界—证书”；
- 逐条纠正常见误解；
- 三人轮换做讲解者、追问者和证据检查员；
- 完成终章挑战，不看书做一次微型答辩。

<div class="teacher-note">

**给带队教师**：不要以“读了多少页”判断进度。每次训练只选一个核心句，让学生画图、举反例、换一种说法，再由同伴指出缺失条件。能指出一句话的适用边界，比背出整段证明更接近真正理解。
