终章挑战：不看论文，也能把因果讲完整

先独立完成，再与队友交换批改。满分不在于小数背得多，而在于条件与证据都不丢。

A. 会看图¶

  1. 图上一个机器人中心恰在半径9禁圆边界，是否安全？为什么？

  2. 三角网格地址 (2,−3)(2,-3)(2,−3) 在第几层？

  3. 九点图中线段24与35交叉，交点是否自动成为顶点？

  4. 两个三角形123与145满足“不共边”吗？满足“顶点不交”吗？

B. 会算小例¶

  1. 第一层沿30°直走，最近垂距是多少？

  2. m=12m=12m=12 时求 q,rq,rq,r 和 KK⁡(12)\operatorname{KK}(12)KK(12)。

  3. 固定图 HHH 加边23、24、34后有哪些三角形？

  4. 已知 T9(23)=35T_9(23)=35T9​(23)=35、T9(24)=36T_9(24)=36T9​(24)=36，求 E(9,36)E(9,36)E(9,36) 并说明两侧证据。

C. 会辨证据¶

  1. “8卡随机搜索十万次没找到”属于定理、构造、实验还是反例？

  2. “保存了一个29边、56三角形的边集”能证明 E(9,56)=29E(9,56)=29E(9,56)=29 吗？

  3. 为什么445.858与285.492不能画成同条件柱状图后宣布前者更好？

  4. 为什么20万帧动画仍不能单独证明连续时间无碰撞？

D. 会讲边界¶

  1. 用不超过60字准确表述 C(2)C(2)C(2) 的当前状态。

  2. 用不超过100字准确表述445.858米结论。

  3. 用不超过100字准确表述一般 E(n,k)=μ(k)E(n,k)=\mu(k)E(n,k)=μ(k) 的范围，并指出一个不在范围内的反例。

  4. 说出题二一般参数仍未闭合的两个 kkk 区间。

E. 研究者题¶

  1. 如果有人声称“每穿一扇门至少用一张转弯卡”，你会怎样找反例？

  2. 如果一套整数规划只输出 FEASIBLE，没有最优界，你会怎样改写报告？

  3. 若稳健安全计算得到静态距离9.04、最大位移0.05，能否证明安全？

  4. 设计一张“结论身份证”，检查任意新结果是否能进入正式答辩材料。

参考答案¶

展开 A 与 B

  1. 安全；题面允许相切，边界上中心距等于9。

  2. 第3层，因为 \max(2,3,1)=3。

  3. 不是；只有题面指定的原有点是顶点。

  4. 不共边，但共顶点1，所以不满足顶点不交。

  5. 20\sin30^\circ=10米。

  6. 12=\binom52+2，所以 q=5,r=2，KK值为 \binom53+\binom22=11。

  7. 123、124、134、234。

  8. E(9,36)=24。23边最多35给下界，24边见证达到36给上界。

展开 C 与 D

  1. 搜索实验，不是不可能性证明。

  2. 不能；它只证明 E(9,56)\le29，还缺28边不可能的最优界。

  3. 两数来自不同信息模型，前者知道统一方向并可选镜像，后者方向未知且固定同一路线；两个数也都是下界。

  4. 任何有限帧都可能漏掉帧间事件，需覆盖整个时间区间的保守下界。

  5. 已证 1\le C(2)\le9；9卡严格可行，零卡不可能，C(2)=9 仍是强猜想。

  6. 在共同刚性旋转、统一方向预先已知且可按方向选原路或镜像的模型中，100卡存在严格安全方案，使终点离原点至少445.858米；这不是最大值。

  7. 对所有 n\ge9 且 57\le k\le\binom n3，有 E(n,k)=\mu(k)。不能提前到56，因为 \mu(56)=28 而 E(9,56)=29。

  8. 5—26与36—50。

展开 E

  1. 找一条直线连续穿过相邻两门，并核对它到相关圆心仍至少9；论文反例垂距约9.526。

  2. 报告“找到一个可行候选，因此给出上界”，不得写精确最优；继续求最优界或增加可核验证书。

  3. 不能，9.04-0.05=8.99<9。

  4. 至少登记：研究量、优化方向、结论类型、适用条件、具体证据、独立复核、数值余量、不能推出什么、来源位置和当前状态。

最后一次口头任务¶

抽签选择一题，用两分钟完成：

  1. 画一张无符号图；

  2. 用生活语言讲直觉；

  3. 写一个核心公式；

  4. 说一条已证结论；

  5. 主动说一条仍未证明的内容。
