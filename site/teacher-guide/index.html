教师指南：怎样带学生真正理解，而不是背答案

这本书的正文已经按“问题从哪里来—为什么需要新工具—证据怎样闭合”重新组织。课堂上不必把每一页讲成知识点清单；更重要的是让学生始终知道眼前这一步正在解决上一段留下的什么困难。

读者起点¶

本书假设学生会：

  • 初中代数与勾股定理；

  • 简单坐标和函数图像；

  • 基本组合计数直觉；

  • 阅读短段 Python 代码，但不要求独立编程。

反三角函数、图论、整数规划、Lipschitz界和区间算术都在使用前给出普通语言解释。学生不必先修完整高等课程，但要能说出每个术语为什么在那一刻出现。例如，Lipschitz界不是一个待背的名字，而是为了解决动画帧间仍可能碰撞的问题。

一堂课可以经历六种动作，但不必套成六个模块¶

  1. 看：先看无符号图，描述发生了什么；

  2. 试：操作滑块、纸模或小代码；

  3. 译：把观察翻成一句数学话；

  4. 证：再引入符号，说明理由与证据；

  5. 辨：修正一句典型过度表述；

  6. 讲：用30—90秒复述。

这六种动作构成一条自然的理解弧线，不要求每页机械地打出六个标题。每次课最多处理两个核心问题。宁可少读一章，也不要让学生在“好像懂”时直接越过“辨”和“讲”。

题一第一课尤其不要从禁圆或 C(n)C(n)C(n) 的符号开始。先请学生完整复述：机器人和障碍分别多大，有哪三类卡片，静态小问要把什么量变小，旋转小问又要把什么量变大。若这四件事还说不清，后面的9、285.492和445.858都没有稳定的落脚处。

分层安排¶

基础队员¶

必须掌握：

  • 半径相加与相切条件；

  • C(1)C(1)C(1)、C(2)C(2)C(2) 的结论等级；

  • 两个旋转模型不能混；

  • 图、边、三角形与固定图；

  • E(n,1)E(n,1)E(n,1) 至 E(n,4)E(n,4)E(n,4)；

  • 见证不等于最优。

主讲队员¶

在基础上增加：

  • 4n+14n+14n+1 卡片账本与 Θ(n)\Theta(n)Θ(n)；

  • 285方案的余量减位移；

  • TTT 与 EEE 互逆；

  • KK 的 q,rq,rq,r 分解；

  • U9U_9U9​ 删点法与57阈值；

  • 最小度三族。

证据队员¶

进一步负责：

  • 连续区间证书的结构；

  • 浮点方向与安全舍入；

  • 三后端最优状态、零差距和见证重计数；

  • 来源文件、冻结哈希与结论账本。

不建议的教学方式¶

  • 一开始投整页论文，让学生逐行翻译；

  • 要求背全部小数，却不问条件；

  • 用动画替代安全证明；

  • 把计算机辅助证明说成“AI算的”；

  • 把尚未闭合区间补成猜想曲线；

  • 只让最强的一名学生长期主讲。

提问顺序¶

当学生说错，不急着给答案，依次问：

  1. 你研究的量是越大越好还是越小越好？

  2. 这个例子证明“能做到”还是“不能更好”？

  3. 你漏了哪个规则开关？

  4. 若把你的句子理解得更强，能找反例吗？

  5. 最保守、仍完全正确的说法是什么？

遇到高阶术语时，可以再补两问：“如果不用这个词，我们现在难以说清哪件事？”“能否先用一句普通话解释，再回到术语？”术语的作用是把已经理解的关系说得更准确，不应成为绕开理解的快捷方式。

学习证据¶

每名队员至少保存：

  • 一张自己画的模型图；

  • 一次 Notebook 输出或互动实验记录；

  • 一条被同伴纠正过的原回答；

  • 一条修订后的标准回答；

  • 一次90秒录音或现场计时讲解成绩。

这套记录比“读完了”更能说明训练进度，也便于比赛前快速定位薄弱点。
